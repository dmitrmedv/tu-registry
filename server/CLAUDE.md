# server/ — домовленості backend

- Express 5 передає відхилені Promise з async-обробників до error handler автоматично; не додавай `asyncHandler` без потреби.
- Вхідні дані контролерів розбирай через `parseRequest()` і наявні схеми з `packages/shared`.
- Для приватних маршрутів використовуй наявні `requireAuth` / `requireRole`; не вигадуй окрему схему авторизації.
- Mongoose `sanitizeFilter` увімкнено: оператори в довірених фільтрах формуй відповідно до наявного використання `mongoose.trusted()`.
- MongoDB має працювати як replica set; транзакції та тестова БД — за наявними утилітами проєкту.
- Файли сканів обробляй лише через наявні модулі `server/src/modules/scans` і відповідні сервіси.
